# 03_day2 — GroupKFold-5 baseline with HGBR + TableVectorizer

**Intent:** Establish the honest grouped-CV baseline. Four models evaluated on the same 5 fixed folds (`GroupKFold(5).split(X, y, groups=patient_id)`).

**Models:**
- DummyRegressor(mean): 16.48 ± 0.06
- Ridge + median imputer (numeric): grouped-CV RMSE ~12 (worse than holdout due to patient split)
- HGBR (numeric, NaN as signal): ~7.8 ± 0.15
- TableVectorizer + HGBR (all features incl. categoricals): **7.50 ± 0.15** ← best

**Key finding:** `rater_id`, `cohort`, `gene` in TableVectorizer add ~0.3 RMSE over numeric-only HGBR. No feature engineering yet.

**Submission:** `submissions/03_skrub_grouped_cv.csv`, best model refitted on all training data.
